# Palma Máquinas · Protótipo do e-commerce

Protótipo estático (HTML/CSS/JS) do e-commerce da Palma Máquinas e Ferramentas.

Versão publicada: https://palma-prototipo.vercel.app

## Como abrir

```
python3 -m http.server 8765   # na raiz do repositório
```

Abra `http://127.0.0.1:8765/src/index.html`. Preview mobile em `src/preview-mobile.html`.

## Estrutura

- `src/` — páginas HTML, `css/` e `js/`
- `assets/` — imagens, ícones, logos e produtos
